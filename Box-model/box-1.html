Paso a paso en github

Para crear un repositorio en git hub, se deben seguir los siguientes pasos para poder lograrlo:

  1. En proyecto CSS crear la carpeta Box-model
  2. Dentro de Box-model crear archivo html llamado box.html
  3. Abrir terminal en VSC
  4. Git status
  5. Abrir github con su usuario
  6. Creamos un repositorio privado con el nombre del proyecto
  7. Iniciar el repositorio: git init
  8. Se realizan los cambios en los archivos del proyecto
  9. Git status para revisar los archivos modificacion
  10. Git add * para agregar los arcivos modificados
  11. Git commit -m "Descripcion del cambio realizado"
  12. Git remote add origin https://github.com/francescovalentinoacostabonnin/CSS.git
  13. git branch -M main
  14. git push -u origin main
