Paso a paso en GitHub

Para crear un repositorio en GitHub, se deben seguir los siguientes pasos para poder lograrlo:

  1. En el proyecto CSS, crear la carpeta Box-model.
  2. Dentro de Box-model, crear el archivo HTML llamado box.html.
  3. Abrir la terminal en Visual Studio Code.
  4. Ejecutar git status.
  5. Abrir GitHub con el usuario correspondiente.
  6. Crear un repositorio privado con el nombre del proyecto.
  7. Iniciar el repositorio con git init.
  8. Realizar los cambios en los archivos del proyecto.
  9. Ejecutar git status para revisar los archivos modificados.
  10. Ejecutar git add * para agregar los archivos modificados.
  11. Ejecutar git commit -m "Descripción del cambio realizado".
  12. Agregar el repositorio remoto con git remote add origin.
  13. Ejecutar git branch -M main.
  14. Ejecutar git push -u origin main.
